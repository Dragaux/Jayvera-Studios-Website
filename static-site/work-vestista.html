Vestista

A lead-capture chat widget and dashboard built for Carbuyus, so no inquiry gets missed after hours.

Year 2026 Status in progress Stack Express,Chat widget,Dashboard
Screenshot — Vestista
01The problem

Carbuyus, like a lot of small businesses, was missing website inquiries that came in outside business hours — no one there to catch them in the moment.

02The build

Vestista is an embeddable chat widget that captures leads directly on the Carbuyus site, backed by an Express server and a leads dashboard protected by a private key.

03The result

Originally built and named "Assistly," then renamed to Vestista across the entire codebase — branding, config, and package files — once the studio settled on the final name.
